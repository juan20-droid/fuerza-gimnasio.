FUERZA - Prototipo web instalable

Contenido:
- index.html: aplicación
- manifest.webmanifest y sw.js: soporte PWA
- assets/: ilustraciones de los 27 ejercicios de tus cinco rutinas

Publicación:
1. Sube TODOS los archivos y la carpeta assets al repositorio GitHub, conservando la estructura.
2. Activa GitHub Pages en Settings > Pages, rama main y carpeta /(root).
3. Abre la URL publicada en Chrome Android y elige Instalar aplicación o Añadir a pantalla de inicio.

Los datos se guardan localmente en el navegador del móvil. Exporta una copia desde Perfil antes de borrar datos o cambiar de navegador.
Las ilustraciones sirven como referencia visual; no sustituyen la supervisión de un profesional.
